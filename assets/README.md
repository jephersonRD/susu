# assets/

Recursos multimedia del repositorio:

- `banner.png` — banner que se muestra en la cabecera del README.
- `screenshots/` — capturas reales del setup extraídas del vídeo demo:
  - `greeting.png` — saludo de bienvenida.
  - `fastfetch.png` — fastfetch con arte ASCII.
  - `yazi.png` — yazi con iconos y colores.
  - `htop.png` — htop con el tema pastel.
- `demo.mp4` — vídeo demo (1080×1080, ~21 s).

El vídeo también está subido como adjunto de GitHub para poder incrustarlo en el
README con un reproductor:

```
https://github.com/user-attachments/assets/13f858ad-4784-4cd5-9140-c553d7fd5483
```

Las capturas se generaron desde `demo.mp4` con `ffmpeg` y se referencian con rutas
relativas desde el `README.md`.
