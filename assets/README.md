# assets/

Recursos multimedia del repositorio:

- `banner.png` — banner que se muestra en la cabecera del README.
- `screenshots/` — capturas reales extraídas de los vídeos:
  - `greeting.png` — saludo de bienvenida.
  - `fastfetch.png` — fastfetch con arte ASCII.
  - `yazi.png` — yazi con iconos y colores.
  - `htop.png` — htop con el tema pastel.
  - `opencode.png` — opencode respondiendo dentro de Termux.
- `demo.mp4` — vídeo demo del setup (1080×1080, ~21 s).
- `opencode-demo.mp4` — vídeo de opencode en Termux (864×1920, ~25 s).

Los vídeos también están subidos como adjuntos de GitHub para poder incrustarlos
en el README con un reproductor:

```
https://github.com/user-attachments/assets/13f858ad-4784-4cd5-9140-c553d7fd5483
https://github.com/user-attachments/assets/84787d13-aef2-4233-bf31-ada74dea9064
```

Las capturas se generaron desde los vídeos con `ffmpeg` y se referencian con rutas
relativas desde el `README.md`.
